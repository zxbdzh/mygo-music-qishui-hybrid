# 只抽 LX 脚本元数据，不执行第三方脚本

导入 LX 脚本地址时，插件只读取脚本文本、抽取其声明的**接口地址、密钥与支持的平台**，不在插件沙箱里执行脚本；同时把 `permissions.network` 声明为 `"*"`，让用户能填任意音源。

## Context

宿主 moejs 运行时没有可用的隔离上下文（`NewRuntime` 是独立全局，跨运行时对象不能互传），`DisableDynamicCode` 也未开启。第三方脚本一旦在插件里执行，就与插件共享同一个全局，可直接读 `host.storage`（含汽水登录态）、`host.setting`，并调用 `host.spawn`。要支持任意脚本又必须放开网络权限，两者叠加等于把任意代码放进登录态沙箱。

## Considered Options

- **执行脚本，模拟 `globalThis.lx`**：能支持签名、加密、动态换源的脚本，但无法隔离 `host`，风险不可控。
- **固定脚本域名白名单**：安全，但每换一个音源就要改 manifest 重新打包，「导入脚本」失去意义。
- **只抽元数据 + `"*"` 权限**：放弃签名类脚本，换来可随意换源、且不执行第三方代码。

## Consequences

- 抽不到 `API_URL` 的脚本（签名、加密、拼接地址）一律判为不支持，回落**官方授权路径**。
- 插件可获得访问任意域名的能力，安装/升级时宿主会提示「可访问任何网站」；插件只把歌曲 ID 发到脚本文本声明的接口域名，不发送账号凭据。
- 非 `qs` 音源（如只支持 `tx`/`wy` 的脚本）导入后会被判不支持，跨平台 ID 映射不在范围内。
